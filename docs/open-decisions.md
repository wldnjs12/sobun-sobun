# 미결정 항목 (임의로 구현하지 않고 여기에 남겨둠)

기획 개편(`기획수정_프롬포트.md`)에서 "애매한 부분은 임의로 정하지 말고 목록에 넣는다"고 명시한 항목들. 구현은 아래 임시값으로 먼저 진행하되(상수로 분리됨), **최종 확정은 PM(최지원)·팀 논의가 필요**합니다.

| 항목 | 임시값(현재 구현) | 상수 위치(구현 예정) | 확정 필요 이유 |
| --- | --- | --- | --- |
| GPS 허용 반경 | 100m | `backend/.../auth/service/LocationCheckService.ALLOWED_RADIUS_METERS` | 실내 GPS 오차가 기기마다 달라서, 데모 리허설 때 실측하고 조정 필요 |
| 커뮤니티 신고 자동숨김 기준 | 3회 | `backend/.../community/service/CommunityModerationService.REPORT_HIDE_THRESHOLD` | 너무 낮으면 악의적 신고로 오남용될 수 있고, 너무 높으면 신고가 무의미해짐 |
| 커뮤니티 카테고리 | 자유 / 질문 / 나눔 / 공구 제안 | `backend/.../community/domain/CommunityCategory`(enum) | 실제 사용 패턴을 보고 늘리거나 합칠 수 있음 |

## 이미 확정됨 (더 이상 열린 질문 아님 — 참고용 기록)

2026-10-03 대화에서 PM이 직접 결정:

- 다른 건물 리소스에 ID로 직접 접근 시 응답 코드 → **403 Forbidden**
- 행동(팟 개설·참여·커뮤니티 입장) 직전 GPS 통과 결과 유효기간 → **캐시 없음, 매번 재확인**
- 주소 등록 가능 지역 제한 → **없음(전국 허용)**
- 아파트 "동" 선택 방식 → **주소 검색 결과의 동 리스트에서 선택**, API가 동 목록을 주지 않으면 직접입력으로 폴백
