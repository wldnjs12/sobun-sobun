# (기록) ④ 최저가 조회 기반 상품 리스트 제공

담당: 김민준(백엔드) + 도우현(프론트) · 관련 화면: ~~S13~~(삭제됨)

다른 3개 기능과 달리 실시간 로직이 없는 **독립 모듈**이라, 초보 팀원 학습용 첫 기능으로 적합합니다.

## 왜 필요한가 (근거)

대표가 팟을 만들기 전 "이 상품을 어디서 사는 게 가장 싼지" 판단할 근거가 없으면 가격 비교 없이 임의로 상품을 고르게 되고, 참여자 입장에서도 "정말 싸게 사는 건지" 확신이 없다. 상품명을 입력하면 최저가를 자동 조회해줌으로써 팟 생성 전 의사결정을 돕고, 참여자에게는 "혼자 살 때 대비 얼마나 절약했는지" 계산의 기준값을 제공한다.

## 사용자 시나리오

1. 사용자가 상품명을 검색창에 입력한다 (예: "계란 30구").
2. 서버가 네이버 쇼핑 검색 API를 호출해 가격순으로 상위 결과를 가져온다.
3. 결과 리스트(상품명, 최저가, 판매처)를 보여준다.
4. 사용자는 결과에서 바로 "이 상품으로 팟 만들기"로 넘어갈 수 있다 (팟 생성 화면에 상품명/참고가가 미리 채워짐).
