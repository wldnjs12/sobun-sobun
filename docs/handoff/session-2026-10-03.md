## 이번 세션에서 추가/변경한 백엔드 (내 담당 ②팟 + 보완)

- `Pod`: `originalPrice`(선택, 절약액 비교용), `pickupPin`(4자리 자동발급, 비참여자 비노출)
- `PodParticipant`: `paidAt`/`pickedUpAt` 자가신고
- 신규 엔드포인트: `GET /pods/{id}/me`, `GET /pods/{id}/participants`, `POST /pods/{id}/paid`, `POST /pods/{id}/picked-up`
- `Settlement.hostPaymentLink`(선택, 대표 개인 송금 링크/계좌 텍스트 — 실제 결제 API 아님)
- `GET /settlements/{podId}` (최종적으로 문소원님 설계 채택: 미확정/없는 팟 → `200+data:null`)

전부 `docs/API_SPEC.md`·`docs/ERD.md`에 반영돼 있습니다. **외부 사업자 연동(카카오 알림톡 자동발송, 토스페이먼츠/카카오페이 결제 API)은 하켓톤 범위에서 원천적으로 불가능해서, 자가신고(`paidAt`/`pickedUpAt`)·개인 링크 붙여넣기(`hostPaymentLink`)로 대체했습니다.** 자세한 이유는 `docs/handoff/settlement-screens.md` 참고.
