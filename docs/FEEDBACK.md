# QA 피드백 (2026-11-04, 로컬)

환경: 프론트 Vite dev(5173) + 백엔드(8080, QA용 Postgres), 주소·지오코딩·영수증 OCR은 Stub. Playwright(Chromium) 모바일 390x844 + 데스크톱 1440x900.
범위: API 접근 제어(건물 격리·사칭), 핵심 흐름(팟 개설 → 참여 2명 → 마감 → 영수증 → 정산 확정 → 송금 표시 → 픽업), 주요 탭 화면.

## 문제 목록 (심각도 순)

| ID | 심각도 | 화면 | 내용 | 상태 |
|---|---|---|---|---|
| F-1 | 중간 | `/pods/:id/complete` | 정산이 확정된 뒤에도 "대표가 영수증을 올리면…" 안내만 남고, 참여자는 정산 결과(송금)로, 대표는 송금 현황으로 갈 버튼이 없었음. 새로고침해도 같음(알림 화면으로만 진입 가능) | 수정: 마감된 팟이면 정산 여부를 확인(10초 간격)해 "정산이 확정됐어요" 카드와 결과/송금 현황 버튼 표시 |
| F-2 | 중간(결정 필요) | `POST /api/community/posts` | 커뮤니티 입장 GPS(`COMMUNITY_ENTER`)는 프론트에서만 확인. 토큰만 있으면 API 직접 호출로 글쓰기 200 | 미수정: 서버 강제 시 "최근 3분" 기준이면 오래 읽다 글 쓰는 사용자가 막힘. 강제 여부·유효 시간 결정 필요 |
| F-3 | 낮음 | `/pods/:id/complete` | 조사 오류 "대표이 …" (6곳) | 수정: "대표가" |
| F-4 | 낮음 | 정산 화면 전반 | 용어 혼용: 팟 상세·모집 완료는 "대표", 정산·송금·픽업은 "팟장" | 미수정 |
| F-5 | 낮음 | 팟 상세(대표 1명일 때) | "지금 인원 기준 1인당 금액 31,500원"(혼자 전액)이 크게 보여 첫인상이 비쌈. 아래에 "3명이 다 모이면 10,500원" 안내는 있음 | 미수정 |
| F-6 | 낮음 | `/my-pods` | 송금 전인 참여자도 정산 확정만 되면 "정산 완료"로 분류 | 미수정 |
| F-7 | 낮음 | 건물 미등록 계정 API | 타 건물 팟 접근 시 "다른 건물의…" 문구(원인은 미등록). 팟 목록은 빈 200 | 미수정(화면은 미등록이면 주소 등록으로 보내서 실제 노출 적음) |
| F-8 | 낮음 | `/settlements/:id/payments` | 이웃이 [보냈어요]를 눌러도 즉시 반영 안 됨(주기 새로고침·수동 새로고침 버튼은 있음) | 미수정 |

참고: 팟 개설 폼의 단위 입력칸은 placeholder가 "롤"이라 채워진 것처럼 보이지만 비어 있음 → 제출 시 "단위를 입력해주세요" 안내가 나와서 문제로 보진 않음.

## 통과
- 토큰 없음/잘못된 토큰 401. 다른 건물의 팟·정산·커뮤니티는 ID 직접 접근도 403 `BUILDING_ACCESS_DENIED`(양방향). `X-User-Id`·`?userId=`·body의 `hostUserId`/`buildingId` 위조 무시
- 같은 건물 비대표의 마감·수정·취소 403, 비참여자 정산 조회 403. GPS 없이 팟 개설 400 `LOCATION_CHECK_REQUIRED`
- 팟 개설: 빈 값 제출 시 항목별 오류, 정상 개설 → 상세 이동. 참여: 동의 체크 전 확정 버튼 비활성, 참여 후 인원·금액 갱신, 목표 인원 도달 시 모집 완료 화면
- 마감: 확인 시트 → 마감, 참여자 화면 실시간 반영(STOMP)
- 정산: `javascript:` 송금 링크 거부(버튼 비활성+안내), https 링크로 확정, 참여자 결과 화면에 토스 링크·[보냈어요], 송금 현황 반영(새로고침 후), 픽업 확인 번호 표시
- 홈·팟 개설·내 팟·마이·알림·커뮤니티: 모바일/데스크톱 가로 스크롤 없음, 콘솔 오류 없음(React Router v7 예고 경고만)

## 재테스트
F-1·F-3 수정 후: 정산 확정된 팟의 모집 완료 화면에서 참여자 → `/settlements/:id/result`, 대표 → `/settlements/:id/payments` 이동 확인. 정산 전(목표 인원 도달) 화면 문구 정상. `npm run build` 통과.

## 미검증
커뮤니티 UI(신고 3명 자동 숨김, 공구 제안 → 팟 개설 연결, 익명 표시), STOMP 다른 건물 구독 거부(코드상 구현), 수정·모집 취소·참여 취소 UI, 새로고침/중복 제출, 실서버.
