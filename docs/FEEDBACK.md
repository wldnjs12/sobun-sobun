# QA 피드백 (2026-11-04, 로컬)

환경: 프론트 Vite dev(5173) + 백엔드(8080, QA용 Postgres), 주소·지오코딩·영수증 OCR은 Stub. Playwright(Chromium) 모바일 390x844 + 데스크톱 1440x900.
범위: API 접근 제어(건물 격리·사칭), 핵심 흐름(팟 개설 → 참여 2명 → 마감 → 영수증 → 정산 확정 → 송금 표시 → 픽업), 주요 탭 화면.

## 통과
- 토큰 없음/잘못된 토큰 401. 다른 건물의 팟·정산·커뮤니티는 ID 직접 접근도 403 `BUILDING_ACCESS_DENIED`(양방향). `X-User-Id`·`?userId=`·body의 `hostUserId`/`buildingId` 위조 무시
- 같은 건물 비대표의 마감·수정·취소 403, 비참여자 정산 조회 403. GPS 없이 팟 개설 400 `LOCATION_CHECK_REQUIRED`
- 팟 개설: 빈 값 제출 시 항목별 오류, 정상 개설 → 상세 이동. 참여: 동의 체크 전 확정 버튼 비활성, 참여 후 인원·금액 갱신, 목표 인원 도달 시 모집 완료 화면
- 마감: 확인 시트 → 마감, 참여자 화면 실시간 반영(STOMP)
- 정산: `javascript:` 송금 링크 거부(버튼 비활성+안내), https 링크로 확정, 참여자 결과 화면에 토스 링크·[보냈어요], 송금 현황 반영(새로고침 후), 픽업 확인 번호 표시
- 홈·팟 개설·내 팟·마이·알림·커뮤니티: 모바일/데스크톱 가로 스크롤 없음, 콘솔 오류 없음(React Router v7 예고 경고만)

## 통과 (2차: 커뮤니티·수정·취소)
- 커뮤니티: 위치가 멀면 입장 차단 + [다시 확인], 빈 글 제출 시 안내, 공구 제안 글 등록, `<script>` 문자열은 글자로만 표시(실행 안 됨), 글쓴이/"이웃 N" 익명 표시, 응답 JSON에 사용자 id·닉네임 없음, [팟 개설하기] → 제목 채워진 개설 화면, 중복 신고 "이미 신고했어요", 신고 3회 → 목록·상세에서 숨김
- 팟: 개설 버튼 연타해도 POST 1번, 참여자 없을 때 수정 → 반영, 참여 취소 → 인원 복구, 모집 취소 → 참여자 화면 실시간 "취소한 공동구매", 홈 목록에서 빠짐

## 재테스트
F-1·F-3 수정 후: 정산 확정된 팟의 모집 완료 화면에서 참여자 → `/settlements/:id/result`, 대표 → `/settlements/:id/payments` 이동 확인. 정산 전(목표 인원 도달) 화면 문구 정상. `npm run build` 통과. F-9 수정 후 숨겨진 글 화면 문구 확인.
