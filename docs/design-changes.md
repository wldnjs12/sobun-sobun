## 수정되는 화면

- **S4 건물 홈 / 팟 목록**: 상단에 건물명(+동) 표시를 하드코딩이 아니라 등록된 값으로. "진행중 팟" 예시 품목을 생필품/가공식품으로 교체(화장지 30롤, 생수 2L×24병 등 — 계란/식재료 이미지 전부 교체)
- **S5 팟 생성**: 커뮤니티 "공구 제안" 글에서 넘어온 경우 상품명이 미리 채워짐을 표시하는 안내 문구를 "최저가 조회에서 가져왔어요" → **"커뮤니티 제안에서 가져왔어요"**로 변경. 제출 버튼 누르면 GPS 재확인(S2') 거침
- **S6 팟 상세**: 참여 버튼 누르면 GPS 재확인(S2') 거침 (기존엔 없던 단계)
- **S11 정산 결과**: `hostPaymentLink`(대표가 입력한 송금 링크/계좌) 표시 카드 + "보냈어요" 버튼 추가 (현재 백엔드엔 있지만 화면이 없던 부분)
- **S15 하단 네비게이션**: 탭 구성을 `홈·최저가·마이`(3개) → **`팟 · 커뮤니티 · 내 팟 · 마이`**(4개)로 변경. "내 팟"은 기존 마이페이지의 "참여한 팟 목록"을 별도 탭으로 승격
- **품목 이미지/예시 전반**: 계란·식재료 관련 이미지·카피 전부 생필품(화장지·키친타월·물티슈·세탁세제·주방세제·섬유유연제·쓰레기봉투·칫솔·치약·샴푸) + 가공식품(생수·라면·즉석밥·참치캔·스팸·과자·커피믹스·음료)로 교체
