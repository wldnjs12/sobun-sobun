# 시연 루트 + 대본 (해커톤 발표, 3~4분)

> 기준: 2026-11-08 밤 최신 main(PR #74까지)과 실서버 데이터(인하대 60주년기념관). 품목은 생필품과 밀봉 가공식품이고, 범위는 건물 단위 격리다. 제품 규칙은 [PRODUCT_SPEC.md](./PRODUCT_SPEC.md)를 본다.
>
> **한 줄 요약**: 커뮤니티 공구 제안에서 **키친타월 팟을 노트북으로 열고**, 폰이 참여하면 노트북 숫자가 **실시간으로** 바뀐다. 마감 → 영수증 정산 → 폰에서 송금 신고 → 픽업 안내 → 수령 완료까지 **팟 하나로** 끝까지 간다.

## 1. 한눈에 보기

- 시연 주소: https://sobun-sobun-eight.vercel.app
- 건물: **인하대 60주년기념관** (인하로 100, 실서버 건물 id 4)
- 비밀번호: 계정 6개 모두 같다. **팀 채팅을 참고한다** (공개 저장소라 여기 적지 않는다).

| 아이디 | 닉네임 | 기기 | 역할 |
| --- | --- | --- | --- |
| **sobun01** | 김인하 | **노트북 (화면 공유)** | 발표자이자 **대표**. 팟 개설·마감·정산 |
| **sobun02** | 이용현 | **폰** | **참여자**. 참여·[보냈어요]·수령 완료 |
| sobun03 | 박학익 | (예비) | 화장지·컵라면 팟 대표. 정산 대체 루트용 |
| sobun04~06 | 최주안·정송도·한미추 | — | 배경 주민 (팟 참여·댓글) |

미리 들어가 있는 데이터 (2026-11-08 재시드 후 확인):

| 팟 | 상태 | 쓰임 |
| --- | --- | --- |
| 코스트코 화장지 30롤 | 2/3 모집 중 (**한 자리 남음**), 대표 sobun03 | 참여 대체 루트 |
| 생수 2L×24병 | 2/4 모집 중 | 홈 배경 |
| 액체세제 리필 2L 6개 | 1/3 모집 중 | 홈 배경 |
| 캡형 물티슈 100매 10팩 | 3/5 모집 중 | 홈 배경 |
| 컵라면 24개입 1박스 | 4/4 모집 중(정원 참), 대표 sobun03 | 마감·정산 대체 루트 |

커뮤니티 글은 4개다. 공구 제안 "키친타월 6롤짜리 대용량 같이 나누실 분…"(댓글 2), 질문, 나눔, 자유 글이다.

팟 카드와 상세의 사진은 이렇게 정해진다.
- 대표가 개설할 때 **상품 사진을 직접 올렸으면** 그 사진이 나온다.
- 안 올렸으면 품목별 예시 사진이 나온다. 시드 팟 5개와 메인 루트의 키친타월 팟이 여기에 해당한다.

홈 [전체] 탭에는 지난 기록도 함께 보인다. 시연에서는 [모집중] 탭만 쓴다.
- 마감: 옛 화장지 팟, 팀 사진 업로드 테스트 "제주 귤 차 티백"(대표 sobun03)
- 모집 취소: 재시드 전의 옛 시드 팟들, 팀 테스트 "티백"

## 2. 시연 30분 전 체크리스트

- [ ] **노트북**: Chrome에서 sobun01로 로그인한다. 하단 탭 [팟] 홈을 띄워 둔다. 화면 공유와 확대(125%)를 확인한다.
- [ ] **폰**: sobun02로 로그인하고 [팟] 홈을 띄워 둔다. 브라우저 **위치 권한을 허용**하고, 화면 자동 꺼짐을 끈다.
- [ ] **영수증 사진** 1장을 노트북 바탕화면에 둔다 (키친타월 영수증, 12,000원 근처). 인식 금액이 달라도 확인 화면에서 고치면 된다.
- [ ] Railway `LOCATION_CHECK_DEMO_MODE=true`인지 확인한다. 실내에서 GPS 확인이 통과하도록 하는 설정이다.
- [ ] Wi-Fi와 개인 핫스팟 백업, **녹화 영상**을 준비한다.
- [ ] 리허설로 데이터가 바뀌었으면 재시드를 요청한다 (Claude Code에 "시연 데이터 다시 만들어줘"). 모집 중인 시드 팟을 모집 취소하고 위 표 상태로 다시 만든다. 마감된 팟은 취소할 수 없어서 [내 팟] 탭에 기록으로 남는다. 메인 루트는 새 팟을 여는 방식이라 기존 팟 상태와 상관없이 돌아간다.
- [ ] 리허설에서 만든 키친타월 팟이 홈에 남아 있으면 혼동되니, 대표 메뉴 [모집 취소하기]로 정리한다. [내 팟]에도 기록이 안 남게 하려면 Claude Code에 "OO 팟 아예 없애줘"라고 요청한다(DB에서 삭제).
- [ ] (선택) 발표 슬라이드 대신 랜딩 페이지로 시작하려면 노트북 다른 탭에 `https://sobun-sobun-eight.vercel.app/intro2`를 띄워 둔다. 로그인 없이 열리고, 문제 제기와 기능을 슬라이드처럼 보여준다.

## 3. 루트 + 대본

> 표의 **조작**에는 화면에 보이는 버튼 이름을 그대로 적었다. **멘트**는 발표자가 그대로 읽어도 되는 문장이다.

### 장면 1. 오프닝·문제 제기 (0:00~0:30) — 노트북

| 조작 | 화면에 보여야 할 것 |
| --- | --- |
| [팟] 홈을 띄운 채 시작한다. 카테고리 칩 "생수·가공식품"을 한 번 눌렀다가 해제한다. | 상단 건물명 "인하대 60주년기념관", 사진이 있는 팟 카드(생수·세제·물티슈·컵라면) |

> 🎤 "화장지 30롤, 생수 24병. 대용량이 싸다는 건 다 알지만, 혼자 사는 사람한테는 너무 많고 둘 곳도 없어요. 설문에서도 공동구매를 망설이는 이유 1위가 '낯선 사람과 만나는 부담'이었어요.
> 그래서 저희는 **같은 건물 이웃끼리, 뜯지 않은 그대로** 나눠 갖는 앱을 만들었어요. 지금 보시는 건 저희가 있는 60주년기념관 주민들의 화면이에요."

### 장면 2. 건물 익명 커뮤니티 (0:30~1:00) — 노트북

| 조작 | 화면에 보여야 할 것 |
| --- | --- |
| 하단 탭 [커뮤니티]를 누른다. | 글 목록 4개 |
| "키친타월 6롤짜리 대용량…" 공구 제안 글을 누른다. | 작성자 "글쓴이", 댓글 "이웃 1", "이웃 2". 하단에 **"이 품목으로 바로 팟 열기"** 카드 |

> 🎤 "커뮤니티는 같은 건물 주민끼리만 보여요. 글쓴이 말고는 전부 '이웃 1, 이웃 2'로만 나와서 부담이 없고, 신고가 3번 쌓이면 자동으로 숨겨져요.
> 마침 누가 키친타월을 같이 사자고 했네요. 댓글로 사람도 모였으니까, 제가 바로 팟을 열어볼게요."

### 장면 3. 팟 개설 (1:00~1:40) — 노트북

| 조작 | 입력값 |
| --- | --- |
| **[이 품목으로 바로 팟 열기]**를 누른다. | 제목이 글 첫 줄로 미리 채워진다 |
| 제목을 고친다. | `키친타월 6롤` |
| 카테고리 | 주방용품 |
| 총 개수 / 단위 | `6` / `롤` |
| 목표 인원 | 3명 (+/- 버튼). 1인 2롤로 자동 계산된다 |
| 총 금액 | `12000` |
| 상품 사진 (선택) | 건너뛴다. 안 올리면 키친타월 예시 사진이 자동으로 나온다 |
| 수고비 | 5% "추천" (기본 선택 그대로) |
| 픽업 장소 | `1층 로비 앞` |
| **[공동구매 열기]**를 누른다. | GPS 확인 후 팟 상세로 이동한다. 상단에 키친타월 사진, 1/3명 |

> 🎤 "글 제목이 그대로 넘어와서, 개수랑 가격만 넣으면 돼요. 6롤을 3명이 **2롤씩, 뜯지 않은 상태로** 나눠요. 상품 사진은 직접 올릴 수도 있고, 안 올리면 예시 사진이 나와요.
> 팟을 열거나 참여하는 순간에는 위치를 한 번 더 확인해요. 주소만 등록하고 실제로는 다른 데 사는 사람을 막기 위해서예요."

(개설 화면이 길면 값은 말하지 말고 입력만 빠르게 한다. 입력은 발표 멘트를 하는 동안 끝낸다.)

### 장면 4. 실시간 참여 — 핵심 장면 (1:40~2:20) — 폰 → 노트북

| 기기 | 조작 | 화면에 보여야 할 것 |
| --- | --- | --- |
| 노트북 | 방금 연 키친타월 **팟 상세 화면을 그대로 둔다**. | 모집 현황 1/3 |
| 폰 | [팟] 홈을 당겨서 새로고침한다. → "키친타월 6롤" 카드 → [참여하기]를 누른다. | 참여 확인 시트, 1인 예상 부담액 |
| 폰 | 동의 체크("마감한 뒤에는 참여를 취소할 수 없다…")를 하고 **[참여 확정하기]**를 누른다. | 참여 완료 |
| 노트북 | (아무것도 안 누른다) | **새로고침 없이 2/3으로 바뀌고, 1인 금액도 바뀐다** |

> 🎤 (폰을 카메라나 청중 쪽으로 들고) "이제 옆집 이웃 이용현 님이 폰으로 참여해 볼게요."
> (노트북이 바뀌는 순간) "보세요, 제가 아무것도 안 눌렀는데 노트북 화면 인원이 **2명으로 바로 바뀌었죠?** 실시간으로 반영돼요. 이용현 님은 2롤을 뜯지 않은 그대로 받게 돼요."

### 장면 5. 마감 → 영수증 정산 (2:20~3:00) — 노트북

| 조작 | 화면에 보여야 할 것 |
| --- | --- |
| 하단 **[모집 마감하기]** → 확인 창 **[마감하기]** | 모집 완료 화면 |
| **[영수증 올리고 정산 요청하기]** (또는 상세의 [영수증 올리고 정산하기]) | 영수증 등록 화면 |
| **[앨범에서 선택]** → 바탕화면의 영수증 사진 | OCR 인식 후 "영수증 금액 확인" |
| 금액이 12,000원이 아니면 금액을 눌러 `12000`으로 고친다. | 총 결제 금액 12,000원 |
| "내 송금 링크 또는 계좌"에 `카카오뱅크 3333-00-0000000`을 입력한다. | |
| **[1인 6,300원으로 정산하기]**를 누른다. | "정산이 확정됐어요" |

> 🎤 "산 뒤에는 영수증만 찍어 올리면 금액을 자동으로 읽어요. 대표 수고비 5%까지 반영해서 1인당 금액이 바로 나오고요. 지금은 두 명이 모였으니 한 명당 6,300원이에요.
> 인식이 틀려도 눌러서 고치면 돼요. OCR이 실패해도 서비스가 멈추지 않게 만들었어요."

- OCR이 실패하면 **"사진 없이 금액 직접 입력하기"**가 뜬다. 그걸 누르고 12000을 입력한다.

### 장면 6. 송금 신고 → 수령 완료 (3:00~3:30) — 폰

| 조작 | 화면에 보여야 할 것 |
| --- | --- |
| 키친타월 팟 상세 → **[진행 상황 보기]** → **[정산 결과 보고 송금하기]** | 1인 최종 금액 6,300원, 대표 계좌(복사 버튼) |
| **[보냈어요]**를 누른다. | "송금 확인을 요청했어요" |
| **[픽업 안내 보기]**를 누른다. | 수령 장소 "1층 로비 앞", 찾아가는 방법 3단계 |
| **[물건을 꺼냈어요 · 수령 완료]**를 누른다. | **"수령 완료!" 팝업** → [건물 홈으로] |

> 🎤 "참여자는 송금하고 [보냈어요]만 누르면 돼요. 앱이 돈을 직접 받지 않으니까 수수료도 없어요.
> 받을 때는 1층 로비에서 내 몫을 챙겨 **뜯지 않은 상태 그대로인지** 확인하고 [수령 완료]를 누르면 끝이에요. 얼굴 마주칠 필요도 없어요."

### 장면 7. 마무리 (3:30~3:50) — 노트북 (선택: 하단 [내 팟] 탭)

> 🎤 "참여자에게는 수수료를 받지 않고, 실제 거래가 성사된 마트와의 제휴 수수료를 수익 모델로 삼으려고 해요.
> 소분소분으로 같은 건물 이웃들이 필요한 만큼만, 부담 없이 나눠 살 수 있게 하고 싶습니다. 감사합니다."

**시간 합계: 약 3분 50초.** 시간이 모자라면 장면 2의 커뮤니티 설명을 줄이고, [팟] 홈 **[모집중]·[전체] 탭 줄 오른쪽 끝의 [+ 열기]**로 바로 개설 화면에 들어간다(이때는 제목을 직접 입력).

## 4. 흔들릴 때 대체 루트

| 상황 | 대응 |
| --- | --- |
| 노트북 인원이 실시간으로 안 바뀜 | 노트북을 새로고침한다(F5). "네트워크 때문에 한 번 새로고침할게요" |
| 팟 개설 실패 (GPS·네트워크) | 개설을 건너뛴다. 노트북은 기존 **코스트코 화장지 30롤**(2/3) 팟 상세를 띄우고, 폰이 그 팟에 참여해 실시간으로 3/3이 되는 장면을 보여준다 |
| 정산 화면이 막힘 | 노트북을 sobun03으로 다시 로그인한다 → 정원이 찬 **컵라면 24개입 1박스**(4/4) → [모집 마감하기] → [영수증 올리고 정산하기]. 참여자 화면은 폰을 sobun04로 다시 로그인해서 보여준다 |
| 실내 GPS 실패 시트가 뜸 | `LOCATION_CHECK_DEMO_MODE`를 확인한다. 당장은 다시 시도 → 창가로 이동 |
| 로그인이 풀림 | 계정표의 아이디와 팀 채팅 비밀번호로 바로 재로그인한다 |
| 전부 안 됨 | 녹화 영상으로 전환한다. "라이브 대신 녹화 영상으로 보여드릴게요" |

| 거짓 주소는 어떻게 막아요? | "주소 등록이 1차, 팟을 열거나 참여하는 순간의 GPS 확인이 2차예요. 건물에서 20km 밖이면 '집에 돌아가서 다시 시도해 주세요'가 떠요. 좌표는 저장하지 않고 통과 여부만 남겨요." |
| 실내에서 GPS가 되나요? / 오늘은 왜 통과돼요? | "실내는 GPS 오차가 커서, 오늘 시연은 서버의 데모 모드로 위치 확인을 통과시켰어요. 실서비스에서는 꺼 두는 설정이에요." |
| 돈 떼먹으면요? | "영수증 기준 실비 정산이라 금액이 투명하고, 대표가 송금 현황을 사람별로 확인해요. 픽업은 미개봉 확인 후 참여자가 [수령 완료]를 눌러 대표에게 알려요." |
| 수익 모델? | "참여자 수수료 0원, 거래가 성사된 마트 제휴 수수료를 목표로 해요." |
| 기술 스택? | "Spring Boot + STOMP WebSocket(실시간), React, PostgreSQL이에요. 사업계획서 예시는 Node.js였지만 팀 역량에 맞춰 Spring Boot로 통일했어요." |
