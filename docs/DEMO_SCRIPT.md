# 데모 시나리오 (해커톤 발표)

> **2026-11 개편 반영**: 품목은 생활용품(미개봉 단위 나눔), 계정 로그인, 동네(반경 1km) 범위. 제품 규칙은 [PRODUCT_SPEC.md](./PRODUCT_SPEC.md).

발표 담당: 김민준 (조작은 백업으로 최지원 또는 도우현이 옆에서 대기)

## 준비물 체크리스트 (시연 30분 전)

- [ ] 시연용 계정 3개 이상 미리 가입 (예: `demo1`·`demo2`는 같은 동네의 서로 다른 건물, `demo3`는 1km 밖 건물). 예전 `?user=2` 방식은 제거됐으니 **브라우저(또는 시크릿 창)마다 다른 계정으로 로그인**한다.
- [ ] 각 계정 건물 등록 완료 — 최소 한 건물은 **건물명 없는 빌라**(예: "인하로67번길 3")로 등록해 "건물명 없어도 된다"를 보여준다.
- [ ] 서버 환경변수로 **데모 고정 좌표 모드**(`LOCATION_CHECK_DEMO_MODE`)를 켤지 미리 정하기 (실내 GPS가 불안정하면 켜두는 걸 추천)
- [ ] 테스트용 영수증 이미지 1장 (휴지·세제 등 생활용품 영수증)
- [ ] Wi-Fi 상태 확인 + 개인 핫스팟 백업
- [ ] **라이브 데모 실패 대비용 화면 녹화 영상** 1개

## 시연 순서 (약 3~4분 기준)

### 1. 문제 제기 (20~30초)

> "휴지 30롤, 세제 4개 묶음. 대용량이 싼 건 다 아는데, 혼자 사는 사람한테는 너무 많고 둘 데도 없어요. 그렇다고 낯선 사람이랑 만나서 나누는 건 부담스럽죠. 그래서 걸어서 갈 수 있는 동네 이웃끼리, 뜯지 않은 그대로 나눠 갖게 만들었어요."

### 2. 가입·온보딩 (30~40초)

- (대표 휴대폰) 회원가입 → 주소 검색 "인하로67번길" → 결과에 도로명·지번이 같이 보임, [더 보기]로 다음 결과 → 건물명 없는 빌라 선택 → 상세주소 "302호" 입력("이웃에게는 보이지 않아요") → 동네 홈.
- 멘트: "주소는 한 번만 등록하고, 상세주소는 저만 봐요. 다른 이웃에게는 '용현동 · 약 300m'처럼 동네 이름과 대략 거리만 보여요."

### 3. 팟 개설 + 실시간 참여 (1분, 가장 중요한 파트)

- [팟 열기] → GPS 통과 → 카테고리 "휴지·물티슈", "코스트코 휴지 30롤", 총액, 총 30롤 · 1인 10롤 · 3명, 수고비 5%, 픽업 안내 "1층 공동현관 앞".
- 화면 A(대표 팟 상세)와 화면 B(다른 계정, 같은 동네 다른 건물)를 나란히 두고, B에서 동네 홈 → 카테고리 필터/검색으로 팟 찾기 → [참여하기]. A의 참여 인원과 1인당 금액이 바로 바뀌는 걸 보여준다.
- 멘트: "제가 참여하는 순간 옆 화면 금액이 바로 바뀌죠? 그리고 저는 10롤을 뜯지 않은 그대로 받아요."

### 4. 동네 범위 + GPS 실패 (30~40초)

- (1km 밖 계정) 동네 홈에 방금 팟이 안 보임. 팟 링크로 직접 들어가도 "우리 동네(반경 1km) 밖의 공동구매예요" 안내.
- (GPS 실패) 등록 건물과 다른 위치에서 [참여하기] → "집에 돌아가서 다시 시도해 주세요" 시트, 진행 차단.
- 멘트: "주소만으로는 거짓 등록이 가능해서, 팟을 열거나 참여하는 순간마다 위치를 한 번 더 확인해요."

### 5. 커뮤니티 (30초)

- 커뮤니티 입장(GPS) → "공구 제안"으로 "세탁세제 4L 4개입 같이 사실 분?" 작성 → 다른 계정이 익명 댓글("이웃 1") → [이 품목으로 팟 열기].
- 멘트: "글쓴이 말고는 전부 '이웃 N'으로만 보여서 부담 없이 제안할 수 있어요."

### 6. 정산 (1분)

- 대표가 [모집 마감] → 영수증 업로드 → OCR 인식 확인 → 송금 링크 붙여 정산 확정 → 참여자 화면에 "1인당 N원 송금해주세요" 알림 → [보냈어요].
- 멘트: "영수증만 찍으면 금액을 읽어서, 대표 수고비 5%까지 반영한 1인당 금액이 바로 나와요."

### 7. 픽업 (10~15초)

- 픽업 화면: 4자리 PIN, "1층 공동현관 앞" 안내, "뜯지 않은 상태 그대로인지 확인" → [수령 완료].
- 멘트: "얼굴 마주칠 필요 없이 비대면으로 가져가요."

### 8. 마무리 (10초)

> "소분소분으로 동네 이웃들이 생활용품을 필요한 만큼만, 부담 없이 나눠 살 수 있게 만들고 싶습니다. 감사합니다."

## 리스크 대응

| 상황 | 대응 |
| --- | --- |
| 실시간 갱신이 네트워크 문제로 안 보임 | 미리 녹화한 백업 영상으로 전환 |
| OCR 인식 실패 | 수동 입력으로 자연스럽게 전환 — "인식 실패해도 서비스가 멈추지 않는다"는 포인트로 활용 |
| 실내 GPS가 안 잡힘 | 서버 데모 고정 좌표 모드를 켜두거나 창가·건물 입구로 이동 |
| 로그인이 풀림(토큰 만료·저장소 삭제) | 미리 적어둔 데모 계정으로 바로 재로그인 |
| 주소 검색 API 장애 | 키가 없으면 Stub 데모 목록으로 진행. 질문 나오면 "실서비스는 행정안전부 도로명주소 API"라고 답변 |
| "식품은 왜 안 돼요?" 질문 | "개봉·보관·유통기한 책임을 개인 간에 지기 어려워서, 상하지 않는 생활용품을 미개봉으로만 나눈다" |
| 기술 스택 질문 | "사업계획서 예시는 Node.js였지만, 팀 역량에 맞춰 Spring Boot로 구현했다" |
