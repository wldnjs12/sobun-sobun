# 외부 API 키 안내

> 네이버 쇼핑 검색 API(옛 최저가 조회)는 더 이상 쓰지 않습니다. 로그인(계정)은 자체 구현이라 외부 키가 필요 없습니다.

아래 외부 연동 중, **토스/카카오 송금은 개발자 API 키가 필요 없습니다.** 키 발급이 필요한 건 네이버 OCR(영수증), 도로명주소 API, 카카오 로컬 API입니다.

## 1. 영수증 인식 — Naver Clova OCR

기능③(대표 수고비 정산)에서 씁니다. 네이버클라우드플랫폼(NCP) 계정이 필요하고, **일반(General) 도메인**과 **영수증 특화 도메인** 두 종류가 있습니다.

- **영수증 특화 도메인**은 별도 신청서를 내고 승인을 기다려야 하고, 도메인을 만드는 순간부터 월정액 요금(최소 요금제 기준 월 1.8만원 선)이 발생하며 "중지" 기능이 없어 삭제 전까지 계속 과금됩니다.
- **일반(General) 도메인**은 승인 절차 없이 바로 만들 수 있어서, **해커톤 기간에는 일반 도메인으로 영수증 이미지를 통째로 넘기고, 응답 텍스트에서 정규식으로 "합계"/"총액" 근처 숫자를 뽑아 쓰는 방식을 추천**합니다. (특화 모델만큼 정확하진 않지만 승인 대기 시간과 확정 비용을 피할 수 있습니다.)

**발급 절차 (일반 도메인 기준)**
1. https://www.ncloud.com 에서 회원가입 (사업자 등록 없이 개인 회원가입 가능)
2. 콘솔 → AI Services → CLOVA OCR 진입, 이용 약관 동의
3. 도메인 생성 → General 도메인 선택
4. Secret Key 발급 버튼 클릭 → **Secret Key**와 **API Gateway Invoke URL** 확보
5. 결제수단 등록이 필요할 수 있으니, 무료 크레딧/요금제는 콘솔에서 최신 정보로 직접 확인해주세요 (문서 작성 시점 이후 변경될 수 있음).

이렇게 받은 값을 `NAVER_OCR_INVOKE_URL`, `NAVER_OCR_SECRET_KEY`로 사용합니다.

## 2. 건물 인증 — 도로명주소 API (행정안전부, Juso.go.kr)

기능①(주소 검색)에서 씁니다. 공공데이터로 무료이고 승인 대기가 없습니다. 카카오 우편번호 서비스·카카오 로컬 키워드 검색 대신 이걸 쓰는 이유(건물관리번호·아파트 동 목록·서버 검증)는 [PRODUCT_SPEC.md 8.1](./PRODUCT_SPEC.md#81-주소-api-선택--행정안전부-도로명주소-apijuso-유지)에 정리돼 있습니다.

**발급 절차**
1. https://www.juso.go.kr/addrlink/openApi/apiRequestPage.do 접속
2. 사업자 등록 없이 개인도 신청 가능, 신청서 제출 후 **승인키(confmKey)**가 바로 발급됨(승인 대기 짧음, 보통 즉시~1일 이내)
3. "주소검색 API" 사용 — 결과에 도로명주소(`roadAddr`), 지번주소(`jibunAddr`), 건물명(`bdNm`, 빌라·주택은 빈 값), 건물관리번호(`bdMgtSn`), 공동주택 여부(`bdKdcd`), 아파트 동 목록(`detBdNmList`), 총 건수(`totalCount`)가 포함됨. 한 번에 최대 20건씩 페이지(`currentPage`)로 받아옴

이렇게 받은 값을 `JUSO_API_KEY`로 사용합니다. 키가 없으면(로컬 개발 등) 자동으로 Stub 구현체가 고정된 데모 건물 후보 목록을 반환합니다(`AddressSearchClient`, `ReceiptOcrClient`와 동일한 real/stub 선택 패턴).

## 3. 건물 좌표 변환 — 카카오 로컬 API

기능①(건물 등록 시 지오코딩)에서 씁니다.

**발급 절차**
1. https://developers.kakao.com 로그인 → 애플리케이션 추가
2. 앱 설정 → 요약 정보에서 **REST API 키** 확보
3. 추가 설정 없이 바로 "주소 → 좌표" 변환 API 사용 가능 (무료 호출 한도 내)

이렇게 받은 값을 `KAKAO_REST_API_KEY`로 사용합니다. 키가 없으면 Stub 구현체가 인하대학교 근처 고정 좌표를 반환합니다.

## 4. 송금 — 토스페이먼츠 / 카카오페이

**개발자 API 키가 필요 없습니다.** 사업계획서의 "송금 링크"는 가맹점 결제 연동이 아니라, **개인 간 송금 기능**(토스 앱의 "송금 링크 만들기", 카카오페이의 "송금 요청")을 말합니다.

- 대표가 본인 토스/카카오페이에서 송금 요청 링크를 만들어 팟 정산 결과 화면에 붙여넣으면, 참여자가 그 링크를 눌러 송금하는 방식입니다.
- 송금이 실제로 됐는지 앱이 자동으로 확인할 방법은 없으니(계좌 조회 API 연동은 범위 밖), 참여자가 "보냈어요" 버튼을 눌러 자가 신고하는 방식으로 MVP에서는 충분합니다.

## 발급 시점

- 각 기능 개발 착수 전에 미리 발급받아두면 좋습니다. 발급 자체는 10분~1일 내로 끝납니다.
- 발급받은 키는 절대 커밋하지 말고, `backend/src/main/resources/application-local.yml`(gitignore 처리됨)에만 넣어주세요. 팀과 키를 공유해야 하면 카카오톡/노션 같은 별도 채널로 전달하세요.
